## Web application
- [ ] Mobile: responsive layout and touch, decided by BDFN 2026-10-12. Touch gestures live in ui-egui and react only to real touch events, so mouse and trackpad are unchanged and native touchscreens benefit too.
	- [x] Touch translator (2026-10-12 5:00 PM EDT): `touch.rs` rewrites raw input before egui sees it, so every widget reacts through its mouse code. A tap clicks; tap then an immediate press holds the button (drag selects, lift double-clicks and edits); one finger scrolls via wheel events, with momentum; two fingers scroll and pinch-zoom; long press right-clicks. Scrolling keeps the pointer where the touch began. Fixed two grid bugs it exposed: a press that becomes a drag no longer counts as a double-click, and a second press on the very next frame is no longer ignored.
	- [x] Thresholds hold on a real device as they are (tap slop 10 pt, tap-then-drag window 0.3 s and 30 pt, long press 0.5 s, momentum time constant 0.325 s); BDFN tried the deployed build and approved them with the phone layout (2026-10-13 12:28 PM EDT).
	- [x] Compact layout, first pass (2026-10-12 5:30 PM EDT): below 600 points wide (`COMPACT_WIDTH`) the status bar hides and the title bar drops AutoSave and Share. Ribbon tabs scroll sideways and carry accessible labels. The title sits between the button groups and shortens with an ellipsis, at every width.
	- [x] Dialogs fit the screen (2026-10-13 1:55 PM EDT): every dialog is capped at the screen size less a 16-point gutter, and its body scrolls when taller. Fixed-width fields narrow to the space left; Find's and Solver's rows wrap; Recommended Charts stacks its list above the preview. Fixed an upstream layout bug: the OK/Cancel row claimed all remaining height to center its buttons, so small dialogs stretched to 420 points and Paste Special filled the whole screen; dialogs now end just below their buttons.
	- [x] The ribbon pans sideways when it overflows (2026-10-13 8:30 PM EDT): a plain vertical mouse wheel over the tab row or the ribbon card scrolls it left and right; a horizontal wheel, trackpad or finger swipe already did.
	- [x] iOS: File › Open › "Import from this computer" never showed the file picker (fixed 2026-10-13 9:50 PM EDT; awaiting a check on an iPhone). Likely cause: WebKit opens a file input only while the browser is handling the tap, but the translator clicks one or two animation frames after the lift, outside it. 	- [x] Phone: the File view (backstage) left bar pushed the page content past the right edge (fixed 2026-10-13 9:50 PM EDT). Below the compact width the navigation becomes a row along the top that scrolls sideways; pages cap their width at the screen; Print stacks the preview under its settings.
